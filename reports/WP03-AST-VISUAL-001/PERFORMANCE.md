## 真实文件的完整分析和动画

通过项目导入接口写入 `channels.py`，其中 27 个类各含 36 个有函数体的方法。浏览器访问真实 F02 路由，分析 GET 完成后使用默认 Cinematic 动画，最后检查统计、符号树、重播和 reduced-motion。

| 本次观测 | 数值 |
| --- | --- |
| 图谱规模 | 1 文件 + 27 类 + 972 方法 = 1000 节点，999 条真实包含边 |
| 分析 GET 往返 | 74.7 ms |
| 文档响应结束至检测到 COMPLETE 和已填充统计 | 3062.2 ms，含有意播放的渐进式呈现及浏览器断言开销 |
| 正常动画的图谱绘制 | 164 次 |
| 绘制帧间隔中位数 / P95 | 16.7 / 16.9 ms |

测量在同源页面读取 Resource Timing 的分析请求 `duration`。测试为目标 canvas 的 `clearRect` 添加只计时的探针，记录每帧实际绘制开始时间，以相邻帧的间隔计算分位数。这些数值分别描述 HTTP 往返和界面绘制节奏。服务端没有提供单独的 AST 解析耗时，用户界面仅标记请求往返。

## 1000 节点／2000 边的独立渲染预算

单文件包含树有一个根，每个定义有一个父级，1000 节点对应 999 条结构边。为测量更多连线的成本，将该真实模型传给相同的生产渲染器，在单独的测试 canvas 上加 1001 条标记 `stress` 的有向线段。该数据只存在于测试内存，没有提交给后端，也没有出现在业务页或交付截图中。

画布大小 1200 × 720 CSS px，使用系统减少动态效果设置。测试核对单击选中、双击邻域聚焦、空白清选、平移 60 × 40 px 及复位。随后交替放大／缩小 40 次，每次等到下一次绘制机会，最后静置 600 ms 计数。

| 本次观测 | 数值 |
| --- | --- |
| 构造布局和渲染器句柄 | 7.0 ms |
| 缩放指令至下一次帧回调的中位数 / P95 | 16.6 / 17.1 ms |
| 静置 600 ms 新增图谱重绘 | 0 次 |
| 减少动画下的阶段回调 | 一次 COMPLETE |

## 重现与解释

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_ast_studio.py -q -s -k 'large_real_analysis or dense_renderer'
```

控制台的 `REAL_LARGE`、`SYNTHETIC_RENDERER` 分别对应这两组输入。交互响应数据包含浏览器调度时间；静置测量只统计图谱的重绘。实际 GPU、浏览器缩放、硬件负载与同时打开的页面均可能改变测量结果。此轮没有采集系统级 CPU 占用、显存或整进程能耗。
