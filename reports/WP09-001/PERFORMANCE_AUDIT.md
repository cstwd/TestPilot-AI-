# WP09-001 性能与稳定性回归

实测环境为 Windows 11、Edge 158.0.4370.33、Playwright 1.65.2 和 Python 3.13.11。各项记录为本机一次测量，帧间隔包含 Edge 调度开销，HTTP Resource Timing 衡量浏览器往返读数。GitNexus 风格图谱继续使用原有稳定布局、Cinematic 分批绘制和 `prefers-reduced-motion`。

## F02 动画、离页和重播

- 真实 Edge 缓存往返中，第一次离开触发 `pagehide.persisted=true`，浏览器后退触发 `pageshow.persisted=true`，文档实例相同。随后刷新触发 `pagehide.persisted=false` 与新文档实例。该实测使用允许原生 BackForwardCache 的 Edge 启动参数。 [原生事件记录](raw/edge-bfcache.txt)
- 在实际 Canvas 上通过等价的生命周期事件输入检查内部状态。回放离页后待执行帧为 0，150 ms 内绘制计数稳定，恢复时出现 1 个待执行帧。手动暂停跨往返保留，最终离页后 3 组已跟踪监听信号全部中止，待执行帧为 0，`/` 快捷键不再聚焦离页工作台。 [生命周期输出](raw/integration-edge.txt)
- F02 原有状态测试覆盖等待提示、加载失败、手动暂停、继续、重播和尺寸变化，继续通过原有断言读取完成状态。页面计时名称仍为“分析请求（浏览器端）”，包括请求及响应的 JSON 解析。

## F04/F05 长日志

验收输入在已允许的 WASI 中生成一行 12,000 次 `bounded-line-` 的标准输出。F04 持久化日志为 157,486 字节。390px 视口中 `clientWidth` 和 `scrollWidth` 均为 390px。搜索只创建 300 个高亮，输入到第二个动画帧在独立验收中为 30.0 ms、全量回归中为 38.2 ms。界面文本及复制结果与持久化日志逐字符一致，剪贴板换行统一后比较。F05 原始运行日志沿用相同换行策略。现有专用回归继续检查截断和空日志。

## F06 报告与全站请求

主线 7 次写请求均与业务操作一一对应，刷新、前进、后退、HTML 与 JSON 导出均未产生额外写请求。独立 HTML 从已加载的同一报告生成，运行、版本、计数、分母、缺陷及回归与 JSON 一致。页面展示的缺陷状态保留报告读取时的状态口径。 [完整业务闭环](END_TO_END_ACCEPTANCE.md)

本次覆盖响应式尺寸、画布帧、真实日志操作与报告快照。系统级 CPU、显存、能耗和物理移动设备未纳入本次测量。
