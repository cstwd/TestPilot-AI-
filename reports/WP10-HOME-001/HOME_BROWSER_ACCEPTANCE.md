# WP10-HOME-001 Edge 浏览器验收

使用 Windows 11 的 Microsoft Edge 158.0.4370.33。浏览器通过 `main.py` 启动的真实 FastAPI 服务读取隔离 SQLite。正常启动探针在 Edge 自动化连接之前已观察到默认浏览器请求 `/`，随后 Edge 核对标题和 SQLite 状态。 [启动原始输出](raw/main-start.txt)

## 交互与真实数据

| 路径 | 观察 |
| --- | --- |
| 根页与健康 | `GET /` 为 200。FastAPI 和 SQLite 显示已连接，记录检查时间。503 故障注入保留服务连接并显示数据库异常，离线时显示连接失败和 SQLite 状态无法确认，恢复网络后实测重查。 |
| Pytest 自检 | 由首页发出真实 `POST /api/self-test`，固定样例返回 `1 passed`。终端内容逐字对应 `detail`。忙和失败分支使用明确标识的 409 / 503 注入。设置可保存是否自动展开输出。 [自检实拍](screenshots/home-self-test-1440x900.png) |
| 首页快捷操作 | 390px 无项目时从导入进入创建表单。确认持久化项目后，打开所选项目的上传锚点，验证 F01 上传控件可用。已有项目时确实导入 `review.py`，返回首页显示该最新文件。项目重名显示服务端的 409 提示。 |
| 近期项目恢复 | 在两个真实项目间选择活动范围，最新创建项目仍单列显示，详细活动随所选项目清除或恢复。从首页打开该项目后，恢复入口指向已打开项目。从无参数工作台经品牌入口返回，也按实际默认项目恢复。 |
| F01–F06 与工具 | 在首页点击八个真实入口，核对最终地址、响应状态和目的页标题。两个外部工具原有 Playwright 流程也走首页入口。 |
| 最近活动 | 项目 `#2`、`telemetry.py` v1 `#1`、v2 `#2`、套件 `#1`、原始失败运行 `#1`、修复运行 `#2`、缺陷 `#1`。首页各证据链接保留 API 提供的项目、版本、套件与运行身份。 |
| 空数据和错误 | 空数据库、单类文件查询 502、服务离线均显示不同状态。项目列表失败提示无法读取项目，不将网络错误当作空记录。 [空态](screenshots/home-empty-390.png) · [离线](screenshots/home-offline-390.png) |

样例由验收用例生成在隔离数据库，F03 采用现有模板模式，业务测试与修复回归走真实受限执行器。输出中的 `WP10_ACTIVITY` 是本次真实记录的身份索引。
