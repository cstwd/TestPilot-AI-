# 功能与验收映射

PHASE-01 提供本机单服务、Dashboard、数据库探测和可信自检。下表是后续功能的验收草案。业务功能完成时，应提交实际样例、运行结果和复查入口。

| 编号 | 功能与负责包 | 输入 → 输出 | 最小验收场景 | PHASE-01 状态 |
| --- | --- | --- | --- | --- |
| F01 | 项目管理和文件导入 · WP01、WP02 | 项目名、Python 源文件 → 项目记录、文件清单 | 创建两个项目并导入不同文件，刷新后各自清单可恢复；不支持的文件和越界路径被拒绝，已有文件不受影响 | 已定义，待实现 |
| F02 | Python AST 代码分析 · WP01 | 已导入文件 → 带文件与行号的分析结果 | 对含函数、类及语法错误的样例分别验证符号、定位和错误提示；分析阶段不执行源码 | 已定义，待实现 |
| F03 | AI 测试用例生成 · WP03 | 符号、源码上下文、生成配置 → 可审阅的测试源码与生成记录 | 选定函数后生成普通用例和适用的属性测试，保留生成输入摘要，检查测试可收集；生成失败应可见 | 已定义，待实现 |
| F04 | 自动化测试执行 · WP03、WP04 | 经选择的测试和目标代码 → 运行结果、耗时和日志 | 在通过隔离验收的环境运行预设成功、断言失败和超时样例，核对三个状态及清理结果 | 仅平台固定自检可验收，用户代码执行待实现 |
| F05 | Bug 管理和回归验证 · WP04 | 失败运行、修复版本 → 缺陷记录、回归证据 | 从失败断言创建缺陷，定位原运行；对修复版本用同一测试复跑，保留两次记录并按结果更新状态 | 已定义，待实现 |
| F06 | 测试质量评估和报告导出 · WP03、WP04、WP05 | 运行记录、覆盖率、缺陷与回归 → 可导出报告 | 对固定样例核对用例数、通过/失败/错误数、覆盖率和缺陷链接；指标无数据时注明缺失，导出内容与页面一致 | 已定义，待实现 |

WP02 对各阶段界面反馈与交互负责，WP01 负责联调，WP05 归档证据。具体负责人见 [成员贡献分配表](../collab-log/member_contributions.md)。
