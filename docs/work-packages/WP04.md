# WP04 · Bug 管理、质量检查与安全验证

| 工作包字段 | 内容 |
| --- | --- |
| 负责人 | 马雪朋；计划团队贡献占比 20% |
| 任务说明 | 设计缺陷生命周期与回归证据；复核测试执行隔离、错误处理及阶段质量门槛。 |
| 输入 | 风险清单、运行结果、源码或用例版本、异常与修复信息。 |
| 输出 | 风险登记、缺陷工作区、隔离验收条件；业务阶段生成缺陷与回归记录。 |
| 验收标准 | 固定平台自检与用户项目执行分离；业务执行前有经实测的权限和资源限制；缺陷可追溯到失败用例并保留修复前后证据。 |
| 关联文件 / 目录 | `docs/RISK_REGISTER.md`、`collab-log/bugs`、`tests` |
| Git 记录 | 从仓库根目录执行 `git log --oneline -- docs/work-packages/WP04.md docs/RISK_REGISTER.md collab-log/bugs tests`，核对相关提交及差异 |
| 验收结果 | 风险与安全边界已登记，F05 和业务运行器待实现。后续隔离验收成功前保持业务执行关闭。 |

本阶段文档实际操作人为 Codex，项目组长负责协调；个人操作须有独立记录。启动证据及最终阶段判定见 [TP_PHASE_01_ACCEPTANCE.md](../../TP_PHASE_01_ACCEPTANCE.md)。
