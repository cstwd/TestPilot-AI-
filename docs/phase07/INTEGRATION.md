
# TP-PHASE-07 Demo Lab 集成方案

WP01 联调、WP02 产品交互、WP03 测试、WP04 质量、WP05 取证。工作包联调责任人为陈帅廷，操作者 Codex。

- FastAPI 提供同源工作台入口 `/workbench/demo-lab`。样本列表读取冻结的公开索引，源码和修复版按固定路径及 SHA-256 读取。公开合同从函数文档、产品模板和本阶段新写的课堂用例构建。运行时无需访问隐藏标准答案与离线验证。
- 演示 SQLite 与主项目库并列。每次运行创建独立项目，复用 F01 导入、F02 AST、F03 生成与套件存储、F04 WASI、F05 缺陷与回归、F06 质量报告、F13 引擎会话。服务端后台编排可独立于页面连接完成，按步骤提交证据。OS 文件锁防止两个服务同时持有相同演示库的运行，进程重启后保留中断记录。重新执行创建新实验。
- 默认使用公开合同模板，明确标注来源。用户显式选择本机 AI 时先进行模型源码理解，再用真实 AI 生成。模型拒绝保留诊断。修复采用同文件已冻结的参考版本。F13 使用当前通过版本和相同套件，照常执行原版基线、清单与变异。
- 界面沿用工作台的深色、紫色交互和等宽代码。左侧按样本类型与领域筛选，右侧优先展示样本、运行入口与执行时间线。下方分区展示源码、公开合同、运行历史和报告。窄屏使用纵向布局。
- 演示报告保存在独立实验记录，包含已观测的证据和 JSON 下载。课堂代码、历史评测、生产运行接口的原有行为及 F13 口径继续由原模块管理。
