| 模块 | 实际审查及处理 |

| F01 | 核对事务、文件名、按项目分版和并发重复导入。用 Python 3.13 支持的 Windows 保留名检测替换弃用接口。 |
| F02 | 补上条件语句中的函数定义和相应回归。区分保存的源码大小上限与完整 HTTP 报文大小。 |

| F05 | 统一 SQL 与页面的文件名比较规则，只从可重跑的用例节点登记；回归必须核对原节点通过。 |
| F06 | 核对跳过、缺失、实际覆盖行及缺陷状态的时间口径。实际下载 JSON 与 API 返回一致。 |
| 集成 | 首次全套测试中，Edge 已跳转到新运行页时，验收脚本再次读取上一页面的 POST 响应体产生时序错误。改为确认 POST 成功，随后按新页面运行 ID 读取持久化记录。运行结果见总报告。 |
