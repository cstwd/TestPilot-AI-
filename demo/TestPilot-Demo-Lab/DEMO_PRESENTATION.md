
# 课程展示讲解方案

建议 8 分钟。讲解时使用独立项目库和事先核对的源文件摘要，准备好 [实操手册](DEMO_SCENARIO.md)。

| 时段 | 屏幕操作 | 讲解重点 |
| --- | --- | --- |
| 0:00–0:50 | 打开总目录和独立项目 | 100 个模块、六个领域。相同样本可做功能演示，也可冻结成可重复的独立评估。 |
| 0:50–2:00 | 导入 `calculator.py`，查看 AST 和目标函数 | F01 保留文件修订，F02 定位函数，F03 为同一修订生成套件，F04 记录 Pytest 节点。 |
| 2:00–3:20 | 打开 `binary_search.py` 或 `booking_timezones.py` 的 AI 运行记录 | 说明候选测试需要执行并由独立参考重放。展示实际完成状态和失败证据，本机模型不可用时展示归档尝试与错误。 |
| 3:20–5:10 | 导入 `unit_scaling.py`，登记模板导致的断言失败，导入修复版 | 在同一项目从 v1 到 v2。两次运行的套件 ID 一致，缺陷随失败节点通过而关闭。 |
| 5:10–6:10 | 下载两份 F06 JSON 报告 | 对照通过与失败节点、源码摘要、覆盖率和关联缺陷，解释各自统计对象。 |
| 6:10–7:20 | 打开 `calculator.add` F13 记录 | 原版通过后才执行变异。逐条核对 killed 和 survived，并按产品分母解释 Mutation Score。 |
| 7:20–8:00 | 打开独立验收报告与 SHA-256 清单 | 对照 400 个源码合同用例、参考版重跑和定点修复见证，再汇报盲测实得指标。 |

讲解时把每个项目的源版本、目标、生成模式、测试套件、运行 ID 和结论放在同一处。现场模型等待超出安排时，可转到已记录的 F05 回归和 F13 结果，同时按实际状态说明现场进度。
