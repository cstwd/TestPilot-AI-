# TP-PHASE-05 实验口径

工程基线 307d4bd。WP03 评测、WP04 验证，负责人陈帅廷，操作 Codex。固定十个项目（含原 bonus）、三个种子 513/727/941，无条件纳入。四个项目从独立文件导入实际辅助模块。F10 仅挂载 subject.py 和测试文件，评测适配层在 WASI 来宾中按原字节及原文件名加载依赖，主文件字节与变异 UUID 保持一致。适用范围为本评测的纯 Python 顶层模块。

T02 七项各一分，字段顺序无关，值/类型匹配。函数列表、参数签名、示例实际返回、主文件显式分支/循环行、边界的实际返回、指定输入的异常类型、与文档有冲突的语句行分开计分。评分答案及源码在模型输出前冻结。没有源码缺陷时定位答案为 null。评分只衡量所列问题。系统性能按连续完整响应率评分，另列题目正确率、TTFT、token/s、系统总内存及显存的采样峰值。没有外部速度门槛。初始及最终测试质量按全部预登记位置的检出率评分，同时报告有有效基线的 F13 分数。

每次 A/C 分别经 F09 生成，B 每轮重新调用模板，D 使用同轮 C 和存活位置进行独立补测。A/C 使用相同源码、上下文、生成约束和种子。C/D 为配对观测。原版红基线、生成失败和 F09 模板降级记录原始结果，不归为 AI 生成。每个可评分的套件执行所有原始变异。D 即使没有采纳新测试，仍对可用原套件全量重跑。超时、执行错误和等价候选保留在固定清单分母。原版校准通过率按全部实际生成的补测用例计算，同时披露无有效候选的尝试。测试执行成功率以完整返回的真实 Pytest 作业为分子，另列原版绿基线率。时间记录墙钟和模型后端实际返回的 token 计数。模板确定性和两种模型的跨轮测试摘要、分数范围分别披露。

参考目标为初始 ≥55%、补测后 ≥70%、候选通过率 ≥80%。比较以实际差值判定，各组采用相同的九项历史基准和扩展清单。原始项目、评分规则、算子及 F07–F13 实现保持版本化。
