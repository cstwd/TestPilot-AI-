# 项目概述

TestPilot AI 是面向 Python 项目的测试工程工作台。开发者从不可变源码版本定位测试目标，测试人员生成并执行 Pytest，质量人员核对缺陷、同套件回归和导出的质量结果。

需求访谈保留三个实际问答，需求方按原任务书确定方向。项目运行基线为 Windows 11、Python 3.13、PyCharm 和 Edge，主入口为仓库根 `main.py`，同源地址 `127.0.0.1:8000`。
