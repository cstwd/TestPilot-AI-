# 教师可能提问

| 问题 | 回答与证据 |
|---|---|
| 这里的知识图谱是什么关系？ | 图谱主视图以词法包含组织模块、类、函数和方法，Inspector 给出源码位置。在 telemetry.py 中可另外沿源码读 average 调 mean_value。见 P05 和 ast-model.js。 |
| AI 生成和模板结果有什么差异？ | PHASE-06 的 F03 接口 200、mode=ai，有模型名、回环 Provider 和套件源码。普通生成 Studio 的截图是 template。Phase 07 新 AI 演示在分析阶段触发资源守卫，未创建套件。见 P06 和两个原 JSON。 |
| 执行导入源码的隔离点在哪？ | 导入后作为静态数据处理，执行走 runner 和 WASI CPython 子进程。由受限目录、时间等边界保护，失败返回诊断。见 docs/phase03/SANDBOX.md 与 P04/P07。 |
| 怎么证明修复前后是同一个测试？ | P08 的专项原始记录和应用记录关联同一套件 #8、原运行 #12 与回归 #14。P12 的课堂模板另外使用套件 #1、原运行 #1 与回归 #2。查验每个案例自己的文件 ID、SHA 与套件 ID。 |
| 谁修了 unit_scaling？ | P08 里本机 Qwen 生成候选，Codex 驱动浏览器审阅并应用，WASI 单独执行回归。P12 的 Demo Lab 从目录导入已归档修复参考版，使用课堂公开合同。 |
| 变异分数为什么两种？ | geometry 历史会话全部清单 5 项，2/5=40%。有效分母只移除 2 个执行错误，2/3=66.67%。PHASE-05 冻结检出率按预登记 117 个位置计。 |
| CI 每次都调用模型吗？ | Windows CI 复算历史冻结输入、原始输出与评分规则，同时实跑工程测试。前两次 WASI 冷启动超时，预热后第三次通过。 |
| 为什么选 MCP？ | 只读证据接口支持 Agent 通过工具发现和结构化参数读取同一 SQLite 记录。Hook 承担确定性 Git 阻断，独立 Reviewer 检查实际失败与回归。 |
| 50 个 BUGGY 是否全部已实跑？ | 目录冻结 100 项，PHASE-07 七个代表样本有端到端回执。目录条目和实跑数分别是两个口径。 |
| 五人各 20% 如何理解？ | 五人是课程责任分配，实际操作按原日志登记；教师在个人答辩后另定 0.8–1.2。 |
